# Local Coding Agent bootstrap fix — 2026-08-11

## Fixed

- `RUN-CONTINUE-TOOL-SMOKE.ps1` no longer stores CLI arguments in PowerShell's automatic `$args` variable.
- Smoke diagnostics now print the real Continue argument list.
- Continue is invoked through the exact command discovered by `Get-Command cn`.
- `--verbose` is enabled for runtime diagnostics.
- Added `TEST-CONTINUE-PREFLIGHT.ps1` to fail fast on:
  - missing/broken Continue CLI;
  - unreachable Ollama;
  - missing primary model;
  - unusable Continue headless runtime / first-run authentication.
- `DEV.ps1 install` now runs Continue/Ollama preflight before the expensive full regression suite.
- Added `SETUP.ps1` and `SETUP.cmd` as the canonical bootstrap entry point.

## Current Continue CLI constraint

Current Continue CLI releases document a first-run authentication requirement (Continue login or supported API-key flow). This package still routes inference to local Ollama via `apiBase: http://127.0.0.1:11434`, but the Continue CLI authentication step itself is not air-gapped.

If preflight reports a silent Continue exit, run:

```powershell
.\SETUP.ps1 -LoginContinue
```

Then rerun:

```powershell
.\SETUP.ps1
```

## dev.2 — adaptive Continue/Ollama tool-model selection

Observed on the target Windows host: Continue CLI 1.5.47 can load the configured local Ollama model and complete a headless non-tool request, while the real Edit/Write headless phase exits 1 with no output for qwen3.5:9b-q4_K_M.

Changes:
- added `tests/SELECT-WORKING-TOOL-MODEL.ps1`;
- bootstrap tests installed candidate models with a real temporary-file edit instead of trusting metadata/capabilities;
- first passing model is persisted into `config/config-agent.yaml`, `config/config.yaml`, and `config/selected-tool-model.txt`;
- fallback candidates prefer coding/tool-capable models already present on the machine;
- `SETUP.ps1` and `DEV.ps1 install` now use the selector before the final release gate.

This intentionally treats model metadata (`tools`) as insufficient evidence. The acceptance condition is an actual filesystem edit through Continue CLI.
